# 蓝绿 / 灰度 / 滚动发布（图解补充）

- **蓝绿**：绿生产 → 蓝新版本验证 → LB 切流 → 旧环境保留回滚 → 稳定后销毁旧环境并角色互换。
- **灰度**：90/10 起步，观察后逐步加大新版本权重；问题只影响小流量。
- **滚动**：同环境分批替换实例；成本最低；回滚麻烦；相对有损。

选型同 deploy-strategy 对比表：稳定性要求极高→蓝绿；用户体验敏感→灰度；资源紧且可容忍短损→滚动。
