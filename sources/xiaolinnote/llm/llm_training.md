# 大模型怎么训练：预训练 → SFT → 对齐

- 预训练：海量清洗文本，目标是预测下一 token（CLM）。天花板在这里。数据清洗成本可高于训练本身。
- SFT：把续写机器改成对话机器。（指令，回答）对，质量重于数量。
- 对齐：RLHF（偏好排序 + 奖励模型 + PPO）或 DPO（好/差回答三元组，无需奖励模型）。不要把 Llama 2 说成全是 DPO。

缺一不可：只预训练不会对话；只到 SFT 会答但价值观不稳；跳过预训练是在空壳上对齐。
