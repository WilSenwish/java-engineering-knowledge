# 幻觉

定义：流畅但与事实、输入或已知世界不一致。根因：语料有噪声；模型是续写器不是数据库（无「查无此条」）；对齐偏好「自信回答」抑制拒答。Temperature=0 仍会幻觉，因为最高概率路径本身可以是错的。

三类：事实性、推理性、上下文不一致（违背用户给定材料）。

缓解三层：训练加拒答与校准；推理用低温、CoT、Self-Consistency、约束解码；系统用 RAG、引用、事后核查。目标是降低发生率并让用户能识别，不是消灭。
