# HTML 内容站规约

本规约约束 `tools/build_site.py` 生成的静态站。改样式或生成逻辑时先对照这里，再改代码，然后重新构建。

视觉参照：`AI-Engineering-Knowledge/site`（浅灰底、蓝紫光晕、顶栏、左侧目录、圆角卡片）。搜索必须保留。

## 构建

```bash
python3 tools/build_site.py
python3 -m http.server -d site 8765
```

依赖 Python 包 `markdown`。

- 源只来自 `docs/` 下的知识域 Markdown。`sources/` 不进站。
- 首页由生成器写目录，不直接搬 `docs/README.md`。
- 各篇保持 `docs/` 相对路径，后缀改为 `.html`。站内 `.md` 链接改写成对应 `.html`。外链不动。
- 样式和脚本源在 `site-src/`，构建时复制到 `site/assets/`。不要手改 `site/`，下次构建会覆盖。
- 搜索索引用 `site/assets/search-index.js` 的 `window.SITE_INDEX`，字段是标题、相对路径和正文纯文本。

## 版式

- 顶栏：站名、听、搜索、主题、回到顶部、去到底部、窄屏目录。
- 主题三态循环：浅色 → 深色 → 跟随系统。选择记在 `localStorage` 键 `kb-theme`。
- 左侧目录三层：知识域、篇、当前篇的模块。当前篇所在域自动打开，当前篇高亮。
- 知识域可折叠。篇相对域缩进，并用竖线标出层级。当前篇的模块再缩进一层，用虚线竖线标出。
- 顶栏一条阅读进度。滚动一段后，右下角出现回到顶部、去到底部、主题切换。
- 页面带 `data-root`：首页是空字符串，内页是 `../`。搜索结果链接用它做前缀。

## 正文里什么时候用卡片

- 文首 `>` 引用做成提示卡片：浅底、圆角、细边框。这是允许保留的强调。
- 标题含「核心原理 / 生产落地 / 踩坑规避 / 优化进阶 / 选型对比」的三级节，各自收成 `section-card`。
- 没有上述五段的二级节（例如待补充清单），整节收成 `module-card`。
- 首页每个知识域收成一张 `module-card`，里面是该域的篇列表。
- 长段落、代码块、表格留在所属卡片内部，不再单独套一层卡片。

## 线条

默认不画下划线。

- 链接只靠颜色区分。悬停改为更深的字色，不加下划线。
- 标题下不画横线。Markdown 分隔线不画出来。
- 表格保留斑马纹，行间只留一条很浅的分隔；最后一行不加底边。表头不再加粗横线。

可以保留的线：提示卡片的细边框、目录层级竖线、卡片和按钮的细边框、顶部阅读进度条。

## 朗读

- 打开页面后用中文朗读 `article` 正文。按句号、问号、叹号、分号和换行切段，单段不超过约 160 字。
- 顶栏按钮：未读为「▶ 听」，朗读中为「⏸ 暂停」，暂停后再点为「▶ 继续」。
- 默认自动读。键 `kb-listen` 缺省视为 `on`。点暂停后记为 `off`，之后打开的页面不再自动读。再点「听」或「继续」记回 `on`。
- 离开页面时停止朗读。浏览器若拦住自动出声，点一次「听」即可。
